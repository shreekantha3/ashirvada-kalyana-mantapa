# Project Brief

## Project Objective
Build a premium, production-quality demo website for **Ashirvada Kalyana Mantapa**, a wedding and function hall located in Sindagi, Karnataka, India. The website will be shown directly to the venue owner as a sales/demo proposal.

## Target Audience
- Couples planning weddings in the Sindagi/Karnataka region
- Families organizing celebrations (receptions, naming ceremonies, birthdays)
- Event planners seeking venue options
- Community organizations needing function spaces

## Business Context
- **Business Name**: Ashirvada Kalyana Mantapa
- **Location**: Sindagi, Karnataka, India
- **Coordinates**: 16.9196207, 76.2185894 (from Google Maps)
- **Category**: Wedding Hall / Function Venue / Kalyan Mantapa
- **Verified Data**: Business name and location only

## Success Criteria
1. Website impresses the venue owner enough to secure production contract
2. Fully responsive across all device sizes (320px to 1920px)
3. WCAG 2.2 AA accessibility compliance
4. Lighthouse scores: Performance 90+, Accessibility 95+, Best Practices 95+, SEO 95+
5. No fabricated business information
6. Complete documentation and handover materials
7. Clean, professional codebase suitable for production handoff

## Demo Purpose
This is a **demo/sales proposal** website. It demonstrates:
- Premium design and UX capabilities
- Technical competence with modern stack
- Attention to detail in every section
- Professional documentation standards

The demo should feel complete enough that the owner can envision their real website.
